🛠️ Como Utilizar o Menu Superior MVT Jira

Se você precisar antecipar um processo ou homologar os dados, use os comandos manuais direto na barra de menus da planilha:

1. 🎛️ Abrir Painel de Controle Manual

Abre a barra lateral direita para geração manual de cards de períodos específicos. Use se precisar rodar um MVT fora da data padrão ou reprocessar uma Sprint específica.

2. 🔑 Configurar Token Jira Manual

Armazena o seu Personal Access Token gerado no Jira Produção de forma criptografada nos servidores do Google. Só precisa ser feito uma única vez ou caso o seu token expire.

3. 🔔 Forçar Lembrete Manual (Teste) Manual

Simula o gatilho de cobrança imediatamente. O robô envia um e-mail de espelho apenas para você com a tag [TESTE], listando no topo do texto quais e-mails seriam cobrados naquele momento se o disparo fosse o real.

4. 🏆 Forçar Apuração Trimestral (Teste) Manual

Gera o cálculo do MVT Trimestral instantaneamente na sua tela. Para facilitar seus testes em qualquer dia do ano, o modo manual ignora filtros rígidos de data e calcula todas as linhas atuais da sua planilha de respostas externa. Ele envia o e-mail formatado com o vencedor e as justificativas direto para você.

🗂️ Estrutura e Governança das Abas

Para que o código não quebre, mantenha a organização das abas conforme a regra de negócio do ecossistema:

  • TIME: Contém a lista de e-mails oficiais da equipe na Coluna A (a partir da linha 2). O script de cobrança usa essa lista como base comparativa.
  • Logs: Gerada automaticamente pelo sistema. Registra o histórico de buscas (JQLs), horários de envio e diagnósticos de sucesso ou erro das funções.
  • Respostas ao formulário 1 (Na Planilha Externa): O banco de dados bruto onde o Forms descarrega os votos. O script acessa este arquivo remotamente através do ID configurado no código.

💡 Dica de Manutenção: O banco de dados do Google Forms acumula respostas infinitamente. Graças ao filtro de tempo inteligente implementado no script (janela de 4 dias para cobranças e travas trimestrais por data), você não precisa apagar ou limpar as respostas do formulário nunca. O histórico pode ficar guardado ali para consultas futuras sem interferir nos novos ciclos!
